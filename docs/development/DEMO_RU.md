# Как показать MVP

1. Компьютер и Android-телефон должны быть в одной сети. Текущий APK обращается к `http://192.168.8.61:8000`; при смене адреса APK нужно пересобрать.
2. На компьютере запустите `AGRO_API_HOST=0.0.0.0 scripts/start_local.sh`. Уже работающие сервисы можно проверить командой `systemctl --user status agrovision-api agrovision-worker`.
3. Установите `artifacts/android/agrovision-demo-arm64.apk` на ARM64 Android. Это локальная демонстрационная сборка, подписанная debug-ключом.
4. Создайте временный токен: `uv run python scripts/dev_token.py --subject demo-user --output /tmp/agrovision-demo-token`. Откройте этот файл локально и вставьте содержимое в форму «Войти». Токен действует24 часа; не отправляйте его в Git или переписку.
5. Нажмите «Новое наблюдение», выберите пшеницу, картофель или томат. Выберите чёткое фото одного листа через галерею или камеру, проверьте превью и отправьте.
6. Дождитесь результата. Модель действительно обрабатывает изображение и показывает исследовательские гипотезы. Подтверждённый диагноз пока не выдаётся: пороги и полевая работа не валидированы.
7. Оставьте отзыв, откройте историю и повторно откройте сохранённое наблюдение. Фото и история доступны только вошедшему владельцу.

Для воспроизводимой демонстрации через галерею можно взять публичный исследовательский образец `data/images/D05/wheat_leaf/stripe_rust/lolr(1).JPG`. Не представляйте исследовательский пример как независимую полевую проверку.

Проверено в нативном Android30 эмуляторе: вход, системная галерея, фото, очередь, результат реальной модели, отзыв и история. Физическая камера и вход через внешний OIDC-провайдер требуют отдельной проверки. Постоянной офлайн-очереди пока нет; несохранённый черновик находится в памяти приложения.

Измерения и ограничения: [данные и модель](DATA_AND_MODEL.md), [проверки](VERIFICATION.md), [Android](MOBILE_REPORT.md).
