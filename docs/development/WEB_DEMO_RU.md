# Веб-демо AgroVision KZ — как запустить и показать

Веб-приложение работает без базы данных и Docker: один процесс FastAPI отдаёт страницу и считает модель на ONNX Runtime (CPU, ≈0,4 с на фото на Intel i5-10400F).

## Запуск (Windows)

```powershell
# один раз: модель (в Git не хранится) должна лежать в webapp/models/active
#   manifest.json + *.onnx  (копируется с обучающего сервера, см. ниже)
./scripts/run_web.ps1
# открыть http://127.0.0.1:8080
```

Linux/macOS: `./scripts/run_web.sh`. Чтобы открыть с телефона в той же сети: `./scripts/run_web.ps1 -Bind 0.0.0.0` и адрес `http://<IP-компьютера>:8080` (камера в мобильном браузере работает по кнопке «Снять на камеру»).

Копирование модели с сервера (если папка пуста):

```powershell
scp -r maqsat@desktop-dnugqmp-1:agro/bundle_final/* webapp/models/active/
scp -r maqsat@desktop-dnugqmp-1:agro/bundle_clean/* webapp/models/clean/   # вариант без PlantWild
```

Другой путь к модели: переменная `AGRO_WEB_MODEL`.

## Что показывать (сценарий на 3–5 минут)

1. **Главная.** Выбор культуры (или «Авто»), загрузка/съёмка фото, готовые примеры из тестовой выборки под зоной загрузки — достаточно нажать на миниатюру.
2. **Пшеница** — жёлтая, бурая и стеблевая ржавчина, септориоз, мучнистая роса, фузариоз колоса, пыльная головня, здоровый лист (полевые фото JIC, Великобритания, Holeta, Эфиопия, и PlantWild). Это основные болезни зерновых для КЗ.
3. **Подсолнечник** — ложная мучнистая роса, серая гниль. Картофель/томат/кукуруза/яблоня/виноград — примеры из PlantDoc (настоящие полевые фото) и PlantVillage.
4. Кнопка **«Показать, где модель увидела признаки»** — карта активации (CAM): красным области, повлиявшие на результат.
5. **Статусы:** «Уверенный результат» / «Требует проверки» / «Не удалось распознать». Последнее показывается для не-растений и растений вне списка культур (пример «не растение» есть в галерее).
6. **Предупреждения о качестве фото** (размытие, темнота, пересвет, мало пикселей, нет зелени) и предупреждение, если выбранная культура не совпадает с тем, что «видит» модель.
7. **О модели** — состав ансамбля, метрики на внутренней проверке и на независимых «диких» фото, сравнение архитектур, ограничения. **История** — последние 20 анализов, только в браузере.

## Что честно говорить о качестве

Модель — ансамбль из трёх сетей (ConvNeXt-S, ViT-B/16, Swin-T), 47 состояний восьми культур + класс «не целевой лист». Подробности и методика: [KZ_MODEL_BENCHMARK.md](KZ_MODEL_BENCHMARK.md).

| Проверка (фото не участвовали в обучении) | Точность |
|---|---:|
| Тест на источниках обучения (лаборатория + поле) | 99,3 % |
| Полевые фото PlantDoc | 78,0 % |
| «Дикие» фото из интернета (PlantWild, независимая половина) | 75 % по всем состояниям, 87 % — культура определена верно |
| из них пшеница | 93,5 % |
| Фото посторонних растений отклонены | 94 % |

* Статус «Уверенный результат» получает примерно каждое второе «дикое» фото и в 95 % случаев он верен; остальное честно помечается «требует проверки». Именно поэтому результат — гипотеза, а не диагноз.
* **Нет ни одного снимка из Казахстана.** Использованы открытые наборы (PlantVillage, PlantDoc, JIC и Holeta по пшенице, подсолнечник, огурец, PlantWild); пригодность для казахстанских полей не доказана — следующий шаг: собрать локальные фото вместе с агрономами и переоценить.
* Ячмень, сахарная свёкла, лён, рапс, бобовые **не поддерживаются** (нет открытых размеченных данных нужного качества).
* Модель обучена с использованием PlantWild (лицензия CC BY-NC-ND 4.0): **только некоммерческое исследование/демонстрация, веса не публикуются**. Для варианта без PlantWild есть «чистый» набор: `AGRO_WEB_MODEL=webapp/models/clean` (он почти всегда отвечает «требует проверки» — честная калибровка на полевых фото).
* Это не диагноз и не заменяет агронома или лабораторный анализ.

## Устройство

| Часть | Файл |
|---|---|
| API и раздача UI | `webapp/app.py` (`/api/diagnose`, `/api/explain`, `/api/model`, `/api/health`) |
| Инференс (ONNX, TTA, пороги, качество фото, CAM) | `webapp/inference.py` |
| Справочник болезней (рус.) | `webapp/knowledge.json` |
| Интерфейс | `webapp/static/` |
| Примеры + лицензии | `webapp/static/samples/` |
| Обучение, подготовка данных, экспорт | `ml/kz/` |

Тесты: `uv run pytest tests/webapp -q`.
