# An Intelligent Computer Vision System for Plant Disease Diagnosis in Kazakhstan

AgroVision — дипломный проект многокультурной системы предварительной оценки видимых симптомов по фото растения. Основной текущий клиент — React Native/Expo Android; FastAPI и общая платформа предусматривают будущий React web.

## Проблема и пользователи

Фермер или сотрудник хозяйства фиксирует наблюдение на телефоне, получает ограниченную визуальную гипотезу либо объяснение невозможности ответа и возвращается к случаю в истории. Подтвержденные пользовательские потребности: **заполнить после реальных обсуждений**. Планируются локальная проверка в Казахстане и участие агронома.

## Технологии

React Native/Expo, FastAPI, PostgreSQL, приватное S3-compatible storage, PyTorch для обучения и ONNX Runtime как кандидат inference. Модульный монолит с отдельным worker. Выбор и альтернативы фиксируются в ADR.

## Рабочий процесс

Каждая содержательная задача имеет фактический YouTrack ID, владельца, приемку и срок. Изменения выполняются в ветке, проходят review напарника и связываются с задачей. Main содержит просмотренную версию. Перед этапами создаются предусмотренные заданием неизменяемые теги. Каждый участник работает под собственной учетной записью.

## Данные и ограничения

В Git хранятся код, документация и разрешенные manifests. Фотографии пользователей, секреты и большие веса не коммитятся. Права на каждый источник и условия распространения проверяются отдельно. Вывод по фото не объявляется лабораторным подтверждением возбудителя.
