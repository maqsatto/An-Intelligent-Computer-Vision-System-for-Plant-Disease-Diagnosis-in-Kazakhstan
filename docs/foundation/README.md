## Ограничения и происхождение

Источники и предлагаемые протоколы сохраняют исходную дату и статус. Каталог найденных датасетов не доказывает допуск конкретных файлов; актуальный допуск и измерения фиксируются отдельно. План эксперимента, макет, синтетический пример и будущая проверка не являются измеренным результатом.

Текущая локальная research-модель всегда отказывается от диагностического заключения. Ее результаты не подтверждают точность в Казахстане. Production принимает только валидированный release и отклоняет synthetic/research bundles. Правила лицензирования, provenance, независимых split, калибровки, отказа и защиты пользовательских данных сохраняются.

Текущий клиент — Android React Native/Expo. Web и persistent offline queue в исходных документах описывают возможное продолжение и не входят в текущий online MVP. Настоящие изображения, веса, датасеты, секреты и результаты запусков не помещаются в Git.
