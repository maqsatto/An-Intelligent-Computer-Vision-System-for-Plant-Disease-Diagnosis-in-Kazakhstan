# Существующие системы: сравнение для AgroVision

**Дата проверки:** 21 октября 2026 года.
**Тема:** An Intelligent Computer Vision System for Plant Disease Diagnosis in Kazakhstan.
**Назначение:** четыре существующих решения сравниваются по восьми единым критериям.

## 1. Метод и уровень доказательств

Источники — официальные сайты, карточки разработчиков в магазинах приложений и первичная научная публикация Nuru. Приложения не устанавливались, API не вызывались, собственное сравнительное испытание не проводилось. Возможности сервисов ниже являются **документированными заявлениями поставщиков**, а не измеренными результатами команды.

Фраза **«не установлено по изученным источникам» не означает «функции нет»**. Она указывает, где требуются уточнение документации или отдельная проверка. Публичные рекламные метрики не используются для итогового ранжирования качества.

Выбраны Plantix, текущая PlantVillage+, Agrio и **kindwise crop.health**. Последний заменяет общий Plant.id/plant.health, поскольку сам поставщик выделяет его как сервис для сельскохозяйственных культур. API сравнивается по диагностической и интеграционной роли; наличие готового фермерского интерфейса от него не предполагается [K1].

**Исторический PlantVillage Nuru рассматривается отдельно в разделе 3.** Его опубликованные свойства и результаты не переносятся автоматически на нынешнюю PlantVillage+.

## 3. Исторический Nuru: отдельное научное свидетельство

В работе Mrisho et al. (2020) исследовался **PlantVillage Nuru** для симптомов CMD, CBSD и повреждения cassava green mite на маниоке Восточной Африки. В статье подтверждены автономные диагностика и советы, а также влияние количества осматриваемых листьев на результат [N2]. Penn State отдельно описывал локальную Android-обработку повреждений fall armyworm на кукурузе в 2018 году [N3].

Это полезные основания для выбора многоснимочного сценария и исследования работы при слабой связи. Они не подтверждают:

- все функции текущей PlantVillage+;
- текущий полный перечень её поддерживаемых культур;
- качество на пшенице, картофеле и томате в Казахстане;
- полную автономность современных журналов, синхронизации и консультаций.

Карточка package `plantvillage.nuru` на дату проверки имеет имя **PlantVillage+** и дату обновления 20.10.2026 [N1]. Изменение имени/описания требует фиксировать версию при любом практическом тестировании, а не объединять все сведения о продукте за разные годы.

## 4. Ограничения численных и функциональных сравнений

**Каталог Plantix.** 30 культур/780+ повреждений относится к мобильной карточке, 57/970 — к API-странице. Эти значения нельзя произвольно заменять друг другом. Одноимённое приложение другого разработчика в App Store не является доказательством наличия iOS-версии PEAT/Plantix [P2, P3].

**Точность поставщиков.** Plantix API публикует разные результаты для полевых и curated-изображений; crop.health — свои top-1/top-3 показатели. Различия в классах, данных и протоколе не позволяют объявить победителя по этим числам. Собственная проверка должна использовать согласованные состояния и один независимый набор [P3, K1].

**Геоданные.** Возможность сохранять координату и наличие предупреждений о рисках — разные функции. Ни одна сама по себе не подтверждает проверенную эпидемиологическую модель для Казахстана.

**Severity.** Справочное поле о тяжести болезни в crop.health не доказывает измерение процента поражения конкретного пользовательского листа. Для такой функции нужны отдельная документация и проверка [K1].

**Сохранённый API-результат.** Его наличие не равно полноценному фермерскому журналу. Handbook kindwise указывает доступность результата 6 месяцев, а FAQ формулирует гарантию как минимум 3 месяца. Это не универсальный срок хранения для будущего AgroVision; в требованиях своего продукта его нужно определить самостоятельно [K2, K3].

## 5. Обоснование AgroVision

Существующие решения подтверждают практический интерес к фото-диагностике и показывают, какие сценарии уже доступны: рекомендации, мобильная работа, журнал наблюдений, экспертное сообщество и интеграционные API. Поэтому новизну диплома нельзя обосновывать утверждением об отсутствии таких функций на рынке.

Обоснованная задача AgroVision — проверить перенос методов на **конкретные сельскохозяйственные культуры и реальные условия съёмки Казахстана**, определить границы поддержки и оценить поведение системы, когда данных для конкретного ответа недостаточно. Из изученных источников нельзя заключить, что существующие системы плохо работают в стране: для такого вывода потребуется местный сравнительный эксперимент.

Предлагаемый вклад диплома состоит в воспроизводимом протоколе данных, локальной проверке, прозрачном каталоге поддерживаемых состояний и понятном пользовательском сценарии. Обоснование должно соединять эти решения с реальными беседами с пользователями/агрономами. Настоящая матрица не заменяет такие беседы.

| Кандидат требования AgroVision | Как проверить после реализации | Текущий статус |
|---|---|---|
| Поддержка нескольких культур с явным перечнем состояний | Проверить каталог и результаты отдельно по культуре/классу | Предлагаемое требование |
| Ответ при неопределённости и неподдерживаемом случае | Специальная выборка сложных/неподдерживаемых случаев; coverage и ошибки принятых ответов | Предлагаемое требование |
| История осмотра и версия модели | Сохранить запрос, открыть повторно, проверить исходное фото/ответ/версию | Предлагаемое требование |
| Понятные RU/KK формулировки | Проверка терминов специалистом и пользовательские задачи | Предлагаемое требование |
| Экспертная проверка при наличии реального партнёра | Подтверждённый участник, маршрут обращения и проверяемый статус | Требует партнёра и согласованного процесса |

Внешний API можно использовать как дополнительный baseline после проверки доступа, условий, общих классов и разрешения на передачу снимков. Такая интеграция не считается выполненной и не подменяет обучение/оценку собственного исследовательского baseline.

### Ограничения доступности источников

PlantVillage-сайты plantvillage.psu.edu/plantvillage.org блокировали автоматическое извлечение, а plantvillageplus.coop не открылся. Для текущих характеристик использована карточка самого разработчика. Страница IITA была найдена, но не извлечена и не использована как единственное основание утверждения.

Цены, сроки внедрения, пользовательские отзывы и рекламные обещания роста урожая не включены в оценку. Эти сведения не нужны для обоснования исследовательской задачи и не заменяют экспериментальные результаты.
